CICADA technical documentation

Overview Technical guide Core source

Authorized collaboration between native AI sessions

CICADA is a Go system that keeps native session identity, scoped communication, durable delivery and user approval separate from model-generated claims.

Current status: 0.1.0-dev, unreleased; product acceptance PARTIAL. This site documents the development candidate. It does not announce a release or qualify every acceptance gate.

Three deployment responsibilities

Component Responsibility
Node Local native Thread access, Endpoint keys, durable inbox and writer state; outbound Hub connections.
Hub Authoritative state, Directory, Relay and Guard; Control manages user intents and approvals.
Client User identity, review and approval. Android implementation belongs to the independent Client repository.

Logical participants are User, Control, Worker and optional Monitor. Network and Group are authorization and collaboration objects, not extra deployment components. These responsibilities need not occupy separate machines.
